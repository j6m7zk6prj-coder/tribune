# Tribune

App iPhone de football inspirée de FotMob, en SwiftUI natif (Liquid Glass sur iOS 26).

- **Matchs** : tous les matchs du jour, en direct (rafraîchis toutes les 30 s), jour par jour en glissant.
- **Fiche de match** : buteurs, déroulé, compositions sur le terrain, statistiques, classement.
- **Ligues** : Big 5, Ligue des champions, Ligue Europa, Ligue Conférence, sélections (Coupe du monde, Euro, Ligue des nations, qualifications, amicaux), coupes nationales…
- **Suivis** : tes équipes favorites, leur prochain match et leurs matchs en tête de liste.
- Choix des compétitions affichées (bouton réglages de l'onglet Matchs).

Données : API publique d'ESPN (gratuite, sans clé).

## Installer

Onglet **Releases** → `Tribune.ipa`, à installer avec iLoader.
Chaque envoi sur `main` recompile l'app ; les captures du simulateur sont sur la branche `screenshots`.
